# 設備不具合・修理受付

設備の不具合報告から修理状況、費用までをグループで共有する webxdc アプリです。

- **バージョン:** 1.0.0
- **配布ファイル:** `repair-desk_1.0.0.xdc`
- **表示言語:** 日本語

## 利用方法

1. webxdc 対応のチャットアプリで、利用したいグループに `.xdc` ファイルを送信します。
2. チャット内のファイルを開いてアプリを起動します。
3. 「＋ 不具合を登録」から受付を追加します。
4. 一覧の受付を開き、対応状況・修理費用・メモを更新します。

同じアプリの受付データは、ホストとなるチャットアプリの webxdc 更新機能を通じてグループ内で共有されます。実際の同期タイミングは通信状況やホストアプリに依存します。

## 不具合の登録

| 項目 | 入力内容 |
| --- | --- |
| 設備名 | 必須。最大60文字。登録済みの設備名が入力候補に表示されます。 |
| 場所 | 任意。最大60文字。 |
| 不具合の内容 | 任意。最大500文字。 |
| 緊急度 | 「高」「中」「低」から選択。初期値は「中」。 |
| 発生日 | 初期値は当日。未入力で登録した場合も当日になります。 |

登録時の状況は「未対応」です。報告者にはホストアプリから取得した表示名が記録され、受付の履歴が作成されます。

## 一覧・検索

- 「すべて」「未対応」「対応中」「完了」の件数を表示し、状況で絞り込めます。
- 検索は設備名・場所・内容・報告者を対象にした部分一致です。
- 未完了の受付を先に表示し、その中では発生日の新しい順、同日の場合は登録時刻の新しい順に並びます。
- カード左端の色で緊急度を確認できます（高：赤系、中：黄系、低：緑系）。

## 状況・修理費用の更新

一覧の受付を開くと、詳細と更新履歴が表示されます。

1. 「未対応」「対応中」「完了」から状況を選択します。
2. 必要に応じて修理費用（円）とメモ（最大200文字）を入力します。
3. 「更新する」を押します。

更新履歴には日時、更新者、状況、メモが追加されます。同じ状況のままメモを追加することもできます。

修理費用を入力すると、その受付の費用を上書きします。費用欄が空欄の場合は既存の金額を維持し、`0` を入力すると0円に更新します。費用を更新するたびに加算される仕組みではありません。

削除する場合は「削除」を押し、表示が変わった「本当に削除」をもう一度押します。アプリ内に削除の取り消し機能はありません。

## 集計

「集計」では、次の情報を確認できます。

- 受付件数、完了率、修理費合計
- 緊急度別の受付件数の推移
- 修理費用の推移
- 不具合の多い設備（設備名ごと、上位6件）

「月ごと」は選択した年の1〜12月を表示します。「年ごと」の推移グラフは、登録データの年と選択年を基に最大6年分を表示します。年ごとの指標と設備ランキングは全受付が集計対象です。

集計期間は**受付の発生日**を基準にします。修理費もその受付の発生日の月・年に計上され、修理日や費用の更新日で集計するものではありません。修理費合計には未完了の受付に登録された費用も含まれます。

## 仕様・制限

- グループメンバーによる登録・状況更新・削除が可能です。アプリ内に管理者権限や担当者の割り当て機能はありません。
- 登録後に変更できるのは状況・修理費用・メモです。設備名、場所、内容、緊急度、発生日を編集する画面はありません。
- 写真添付、CSV出力、印刷、アプリ独自のバックアップ・復元機能はありません。
- 更新履歴には修理費用の変更前後の金額は保存されません。
- ライト／ダーク表示に対応し、端末の配色設定に追従します。

## ファイル構成

```text
repair-desk_1.0.0.xdc
├── manifest.toml  # アプリ名・バージョン・アイコン・起動HTML
├── icon.png       # アプリアイコン
└── index.html     # 画面・スタイル・処理
```

`index.html` は `webxdc.js` を読み込みます。このファイルは配布アーカイブ内には含まれず、webxdc 対応ホストが提供する環境で動作します。

## ブラウザでの簡易確認

`.xdc` は ZIP 形式のアーカイブです。内容を展開し、`index.html` をブラウザで開くと、webxdc が存在しない場合に簡易モックが動作します。

- 表示名は「テスト」になります。
- 更新データはブラウザの `localStorage` の `wx` キーに保存されます。
- グループ間・端末間の同期は行いません。
- 保存の可否や保持期間はブラウザの設定に依存します。

これは画面や基本操作の確認用です。実際の共有動作は webxdc 対応ホスト上で確認してください。
